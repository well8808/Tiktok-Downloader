# TikTok Downloader

App local em Next.js 14 pra baixar vídeos do TikTok em alta qualidade (1080p sem watermark), com remoção automática de metadados, suportando download individual e em lote.

Roda em `localhost:3000`. Single-user, single-machine. Não tem login, não envia nada pra fora.

## Stack

Next.js 14 App Router · TypeScript strict · Tailwind + shadcn/ui · Prisma + SQLite · yt-dlp + ffmpeg
